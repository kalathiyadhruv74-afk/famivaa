## Quick Commands

### Backend (Django REST Framework - Port 8000)
```bash
cd backend
venv\Scripts\python manage.py runserver 8000
```

### Frontend (React Vite + Tailwind CSS - Port 3000)
```bash
cd frontend
npm run dev
```
